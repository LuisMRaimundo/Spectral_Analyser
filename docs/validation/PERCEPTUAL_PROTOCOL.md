# Perceptual protocol (scaffold only)

This document specifies a listener study that has **not** been run.
There is **no data collection** in this repository. EWSD remains an
acoustic measure until the study below is completed and reported.

## Aim

Test whether listeners' ordering of spectral density (which of two notes
sounds denser / more filled) agrees with the Stage 3 rank of
`EWSD_score_acoustic_balanced`.

## Stimuli

- Isolated sustained notes from one instrument family and one dynamic
  (first campaign: IOWA tuba *pp* SustainStable, or the synthetic
  constructs in `tests/validation/synthetic_corpus/`).
- Equalised presentation level. Same headphones. Randomised A/B order.
- Pair list: adjacent notes in the EWSD ranking, plus a few distant
  pairs. Generated by `python -m tools.perceptual_pairs`.

## Task

For each pair: "Which note sounds spectrally denser (more filled)?"
Optional 1–5 confidence. Forced choice; ties not allowed.

## Response schema

`tools/perceptual_pairs.py` writes `response_template.csv` with:

`pair_id`, `note_a`, `note_b`, `listener_id`, `session_id`,
`denser_choice`, `confidence`, `utc`, `comment`

`denser_choice` must be `note_a` or `note_b`.

## Scoring

`python -m tools.perceptual_agreement --responses filled.csv --ewsd ewsd.csv`

- Win-count per note from the pairwise choices
- Spearman ρ between those scores and `EWSD_score_acoustic_balanced`

Pre-registered success: ρ ≥ 0.70 on the first campaign (n listeners ≥ 8,
all pairs answered). This threshold is a study plan, not a software gate.

## Ethics / data

No recordings of listeners, no personal data, and no filled response
files are generated by this repository. Investigators run the study
outside the pipeline and score the CSV afterwards.
